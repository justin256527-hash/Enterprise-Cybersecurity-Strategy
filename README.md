# Enterprise Cybersecurity Strategy

## Overview

This project presents a comprehensive enterprise cybersecurity strategy developed for a fictional federal contractor, FedCore Technologies, that processes Controlled Unclassified Information (CUI) for the U.S. Department of Defense (DoD) and Department of Homeland Security (DHS).

The objective of this project was to design a risk-driven cybersecurity program that aligns security investments with organizational risk while supporting compliance with NIST SP 800-171 and CMMC Level 2.

The project includes both a formal cybersecurity strategy document and an executive briefing presentation designed for senior leadership.

---

## Project Objectives

- Conduct an enterprise cybersecurity risk assessment
- Quantify cyber risk using Single Loss Expectancy (SLE) and Annual Loss Expectancy (ALE)
- Select an appropriate cybersecurity governance framework
- Recommend strategic cybersecurity initiatives
- Develop an annual cybersecurity budget
- Create executive-level security policies
- Define measurable cybersecurity performance metrics

## Key Components

### Executive Summary

Summarizes the organization's cybersecurity posture, major business risks, recommended security framework, and FY26 investment strategy.

---

### Enterprise Risk Assessment

A quantitative analysis was performed using Single Loss Expectancy (SLE) and Annual Loss Expectancy (ALE).

Highest-ranked risks included:

- Phishing
- Ransomware
- Cloud Misconfiguration
- Supply Chain Risk

These risks were prioritized based on estimated financial impact.

---

### Governance Structure

The project defines executive accountability across:

- Board of Directors
- Chief Executive Officer (CEO)
- Chief Information Security Officer (CISO)
- Security Operations Center (SOC)
- Security Engineering
- Governance, Risk & Compliance (GRC)

This governance model aligns cybersecurity strategy with business objectives.

---

### Strategic Priorities

Three strategic initiatives were recommended:

1. Zero Trust Security Architecture
2. Security Awareness Training
3. Network Segmentation

These initiatives directly address the organization's highest-ranked cyber risks.

---

### Security Investment Plan

An annual cybersecurity investment plan of **$35,000** was developed to fund:

- Multi-Factor Authentication (MFA)
- Endpoint Detection & Response (EDR)
- Email Security Gateway
- Security Awareness Training
- Backup & Disaster Recovery

The proposed budget aligns directly with quantified business risk.

---

### Security Policies

The project includes executive-level security policies covering:

- Remote Access
- Password Management
- Incident Response

These policies establish organizational security expectations and operational procedures.

---

### Cybersecurity Metrics

Key Performance Indicators (KPIs) include:

- MFA Adoption Rate
- Mean Time to Detect (MTTD)
- Mean Time to Respond (MTTR)
- Security Awareness Completion
- Critical Vulnerability Remediation
- CMMC Compliance

These metrics provide measurable indicators of cybersecurity maturity.

## Lessons Learned

This project demonstrates how cybersecurity decisions should be driven by quantified business risk rather than technology alone. It emphasizes executive governance, strategic planning, compliance, and measurable security outcomes while aligning security investments with organizational objectives.
